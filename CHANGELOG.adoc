= Changelog

All notable changes to this project are documented in this file and in link:changelog-details/[per-date detail files].

== [Unreleased]

=== Added

* The product site now carries the organization news note, docs and news links, a light, dark, and auto theme control, and a browser-local settings area (account, identity, vault, mail, household, notifications, privacy, appearance, issuers, companion, developers, this browser). Details: link:changelog-details/2026-11-12-site-redesign.adoc[2026-11-12 — Site redesign].

* Antora component `vault` under `docs/`, including a maintainer page for what to build first. Member-only market sequencing lives in the `userdata-cloud/team-docs` repository.
* GitHub Actions workflow that publishes `apps/site` to the existing Netlify site. Details: link:changelog-details/2026-11-12-org-and-netlify-ci.adoc[2026-11-12 — Org move and Netlify CI].

* Site crawlability: `apps/site` writes `/robots.txt` and `/sitemap.xml` from the shared prerender route list, excluding `/login`, `/app`, and `/identity` from the sitemap.
* AsciiDoc **implementation plans** (index plus per-area roadmaps for desktop, extension, web vault, provider interchange, hardware trust, data model, release signing, and native CLI). Entry point: link:docs/modules/ROOT/pages/plan/index.adoc[plan index].
* Electron + SolidJS desktop shell (`apps/desktop`) with USB-oriented vault path picker, demo graph visualization, and `electron-builder` installer configuration for Windows, macOS, and Linux.
* WebExtension scaffold (`apps/extension`) for Chrome, Edge, and Firefox MV3.
* GitHub Actions workflows for CI builds and tagged desktop releases (artifact uploads).
* SolidStart 1 static site in `apps/site` (`@prv/site`): Kobalte UI, Veramo `did:key` identity, provider export + ephemeral preview, vault merge, privacy hub, Netlify config at repo root. Details: link:changelog-details/2026-05-12-static-site.adoc[2026-05-12 — Static marketing site].
* Bootstrap D `dub` executable and documentation skeleton (now under `native/cli`). Details: link:changelog-details/2026-05-12-bootstrap.adoc[2026-05-12 — Bootstrap].

=== Changed

* Home and vault copy now treats a folder as one storage host. The record is a structured document the issuer signed. The site is not the archive.
* The theme control is part of the first page, so the icon is not a late client download.
* Sora’s Latin file is inlined in the site stylesheet, so the first paint does not wait on a second font request or swap in a fallback face.
* The header and favicon use the symbol from the Vecteezy mark, without the placeholder wordmark. The required credit is on the About page.
* The header name is userdata. The word data is regular Doto, lowercase.
* On load, data is drawn twice in colors that add to white, and the extra copy slides left onto the first. The pair has no background plate.
* The header word data is the same size as user.
* Sign in has its own outlined control. The filled button stays for opening the vault and downloads.

* Public docs for this repository are at `https://docs.userdata.cloud/vault/`.
* The Netlify site name is `userdata-cloud` (`https://userdata-cloud.netlify.app/`). The previous `personalrecordvault.netlify.app` hostname no longer serves the site.
* Implementation plans and explanation pages now live under `docs/modules/ROOT/pages/` so the org docs hub can publish them.
* Primary UX stack moved from D to Electron; D prototype relocated to `native/cli`. Details: link:changelog-details/2026-05-12-electron-monorepo.adoc[2026-05-12 — Electron monorepo].
* Dropped the npm `solid-ui` (SolidOS) dependency from the desktop app; keep **@kobalte/core** on the static site and plain HTML controls in the desktop shell until a deliberate shared design system is chosen.
* Refreshed deprecated `@xmldom/xmldom` (pulled by `electron-builder` via `plist`) to 0.8.15 and 0.9.12 within existing ranges.

=== Fixed

* Remove unused ``core-util-is`` root dependency.

* `@prv/site` production client bundle on Linux/Netlify: `@noble/hashes` Vite aliases now use `require.resolve` so pnpm’s store layout can resolve `sha2.js` / `legacy.js` targets.
* `@prv/site` Vinxi client router build (Netlify): `src/entry-client.tsx` now default-exports the `mount(...)` result so Rollup can bundle `virtual:$vinxi/handler/client` (Vinxi re-exports `mod.default` from the client entry).
